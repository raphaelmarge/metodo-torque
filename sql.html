Atualizar o banco (Supabase)

Este SQL liga as funções novas do sistema: provisionamento de clientes pelo HQ, agenda dos apps e o robô no WhatsApp. Pode rodar quantas vezes quiser — ele pula sozinho o que já existe.

1
Copie o SQL

Toque no botão roxo abaixo — ele copia o arquivo inteiro (carregando…).

2
Abra o SQL Editor do Supabase

Entre em supabase.com/dashboard → seu projeto → menu lateral SQL Editor → + New query.

3
Cole e rode

Cole (toque e segure → Colar) e aperte Run. Vai aparecer Success embaixo — pronto!

4
Confira se pegou

Copie o conferidor abaixo, cole numa nova query e rode. Ele não muda nada — só responde item por item, com ✅ ou ❌, o que está instalado e pra que serve. Item com ❌: rode o SQL do passo 1 de novo.

Depois de rodar, teste assim: abra a Central de Comando → card Novo cliente (provisionar acesso) → cadastre um cliente fictício com um e-mail seu. Se aparecer a senha gerada, tá tudo funcionando. 🎉
